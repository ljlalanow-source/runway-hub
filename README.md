# RUNWAY Hub — 내 포트폴리오 허브 템플릿

가족 AI 스터디 RUNWAY(2026년 9월~12월)에서 만든 결과물을 카드로 모아 보여주는 **나의 허브 사이트** 틀입니다.
첫 번째 프로젝트 "3년 뒤의 나" 프로필 사이트 틀도 들어 있습니다.

## 시작하기 (1회차)

### 1. 내려받기

이 페이지 오른쪽 위 초록 **Code** 버튼 → **Download ZIP**

### 2. 폴더 두기 — 이름은 바꾸지 않습니다

1. 바탕화면에 `AI스터디 RUNWAY` 폴더를 만듭니다
2. 압축을 풀어 나온 `runway-hub-main` 폴더를 **이름 그대로** `AI스터디 RUNWAY` 안에 넣습니다
   - 윈도우는 `runway-hub-main` 안에 `runway-hub-main`이 한 번 더 들어 있을 수 있습니다. **`index.html`이 바로 보이는 안쪽 폴더**를 옮기세요
3. VS Code에서 **파일 > 폴더 열기 → `runway-hub-main`** 선택. 왼쪽 탐색기에 `index.html`, `CLAUDE.md`가 바로 보이면 맞습니다

### 3. 인터뷰

1. **허브 설정 3가지 — 사전 인터뷰 웹사이트에서.** [RUNWAY 사전 인터뷰](https://claude.ai/artifact/AH6NCWH1qJ1j7eym34KCFu)에서 이니셜 · 키컬러 · 2026 엔딩목표를 정하고, 마지막 **결과 복사** 버튼을 누릅니다. 복사된 내용은 단톡방에도 올려 주세요
2. 클로드 코드에 아래를 붙여넣고, 맨 아래에 복사한 결과를 이어 붙입니다

   ```
   이 폴더는 내 RUNWAY 허브야. CLAUDE.md를 읽고,
   work/01-profile/INTERVIEW.md대로 나를 인터뷰해줘.
   한 번에 한 질문씩만 물어봐. 내가 말한 것만 쓰고, 안 말한 건 지어내지 마.
   사전 인터뷰 결과:
   ```

3. **기본 정보**(직무·학력·이메일 등)는 "나중에 입력하시겠습니까?"에서 **예**를 고르면 건너뜁니다. 나중에 "기본 정보 입력할게"라고 하면 그때 묻습니다
4. **3년 뒤의 나 세 질문**(역할 · 대표 프로젝트 · 갖고 싶은 능력)에 답하면 프로필 사이트가 만들어져 게시되고, 허브의 첫 카드로 올라갑니다
5. **공유 설정**: 게시된 페이지는 처음에 나만 볼 수 있습니다. 프로필과 허브를 각각 열어 오른쪽 위 **Share(공유)** → **링크가 있는 사람**으로 바꿉니다
6. 프로필 링크와 허브 링크를 단톡방에

```
바탕화면
└── AI스터디 RUNWAY
    ├── runway-hub-main   ← 허브. VS Code로 여는 폴더. 12월까지 이것 하나만
    ├── 1st               ← 1회차 자료 (강의 노트, 사진 원본 등)
    └── 2nd …
```

`runway-hub-main`은 12월까지 계속 쓰는 폴더입니다. 다시 받거나 옮기지 않습니다.

## 폴더

| 경로 | 용도 |
|---|---|
| `index.html` | 허브 페이지. 다섯 명 공용이라 **고치지 않습니다** |
| `data.js` | 내 소개 + 카드 목록. 내용은 여기서만 |
| `thumbs/` | 카드 대표 사진 |
| `work/<카드id>/` | 결과물 원본 |
| `lectures/<id>/` | (선택) 강의 슬라이드 원본. 스터디에서 강의한 사람만. `data.js`의 `lectures`에 넣으면 Talks 탭이 생깁니다 |
| `work/01-profile/` | "3년 뒤의 나" 프로필 사이트 틀. `INTERVIEW.md`가 인터뷰 대본, `profile.js`가 내용 |
| `tools/capture.ps1` | 결과물 페이지를 캡처해 대표 사진 만들기 |
| `CLAUDE.md` | 클로드 코드가 읽는 규칙. 카드 추가 절차가 여기 있습니다 |

## 회차마다

```
이번 결과물 카드 추가해줘.
```

라고 하면 클로드 코드가 `CLAUDE.md`의 절차대로 카드를 넣고 허브를 다시 게시합니다. 허브 링크는 처음 것을 계속 유지합니다.

## 안전 규칙

- 사이트는 공개됩니다. 전화번호·주소·재직 중인 회사의 내부 자료·고객 정보는 올리지 않습니다.
- AI가 댄 출처나 사실은 확인한 것만 남깁니다.
